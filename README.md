🏦 A console-based Bank Management System built with Python and JSON, featuring multiple accounts, authentication, deposits, withdrawals, transaction history, mini statements, and account creation with persistent data storage.

# 🏦 AR Bank Management System

A console-based Bank Management System built using Python and JSON.

## 🚀 Features

- 🔐 Account Number & PIN Authentication
- 👥 Multiple User Accounts
- 💰 Check Account Balance
- 💵 Deposit Money
- 💸 Withdraw Money
- 🧾 Transaction History
- 📄 Mini Statement
- ➕ Create New Account
- 🔢 Automatic Account Number Generation
- 💾 JSON-based Permanent Data Storage
- ✅ Basic Input Validation

## 🛠️ Technologies Used

- Python
- JSON
- File Handling
- Dictionaries
- Lists
- Loops
- Functions
- Conditional Statements
